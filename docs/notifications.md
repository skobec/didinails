# Уведомления о записях (v1)

## Без настроек: живой вотчер в админке (уже работает)

Пока открыта любая страница `/admin`, раз в 30 секунд идёт тихий опрос:
новая заявка → тост «Новая запись: …» + счётчик в заголовке вкладки `(2)`.
Ничего включать не нужно, но вкладка должна быть открыта.

## Telegram-пуш: бесплатно, мгновенно, даже с закрытым сайтом

Email через Resend подключим позже, когда будет свой домен (сейчас это
overkill: нужен домен + API-ключ + Edge Function). Порядок ценности:
вотчер (уже, $0) → Telegram (10 минут настройки, $0) → email (позже).

## Как это работает

1. Клиент создаёт запись на сайте → строка в `appointments`.
2. Триггер `appointments_notify_telegram` (миграция `0003`) читает настройки
   студии и токен бота из Vault и шлёт сообщение через Telegram Bot API.
3. Отправка асинхронная (`pg_net`): если Telegram недоступен, **запись всё равно
   создаётся** — уведомление просто не дойдёт.

## Настройка (один раз)

### 1. Применить миграцию 0003

SQL Editor → New query → вставить `supabase/migrations/0003_telegram_notifications.sql` → Run.
Проверяем: Table Editor → появилась таблица `notification_settings`.

### 2. Создать бота

- В Telegram открыть **@BotFather** → `/newbot` → имя + username → скопировать токен
  вида `123456:ABC...`.
- Открыть своего бота и нажать **/start** (иначе он не сможет вам писать).

### 3. Положить токен в Vault

В SQL Editor выполнить, подставив токен:

```sql
select vault.create_secret('<TOKEN>', 'telegram_bot_token');
```

Если секрет уже создавали раньше, вместо этого — обновить:

```sql
select vault.update_secret('<TOKEN>', 'telegram_bot_token');
```

⚠️ Токен — как пароль: только Vault, никогда в код/репозиторий/чат.

### 4. Узнать свой chat id

Написать боту **@userinfobot** — он ответит числом, например `123456789`.

### 5. Включить в админке

`/admin/notifications`: вписать chat id → включить чекбокс → Сохранить →
**«Отправить тестовое»**. В Telegram должно прийти
«✅ Уведомления подключены!». Ошибки кнопки говорят сами за себя
(`NO_CHAT_ID` — впишите id, `NO_BOT_TOKEN` — шаг 3 не выполнен).

## Формат сообщения

```
🔔 Новая запись!
Услуга: Маникюр + покрытие
Дата: 12.09.2026
Время: 14:00
Клиент: Анна
Телефон: +7 (999) 123-45-67
```

Дата/время — в таймзоне студии (`businesses.timezone`).

## Лимиты и честность

- Telegram Bot API: ~30 сообщений/сек — для салона бесконечно много, бесплатно.
- Free-проект Supabase засыпает после недели простоя: первая запись «будит»
  базу пару секунд, сообщение всё равно отправится (триггер внутри транзакции).
- Email (Resend) — следующим этапом, когда будет домен: подтверждение клиенту
  + копия мастеру. SMS/OTP для клиентов **не планируем**: SMS платные,
  вместо них — маска телефона + honeypot + time-trap + rate-limit в форме.
